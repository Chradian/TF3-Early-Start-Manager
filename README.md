# TF3 Early Start Manager

Start Transport Fever 3 in 1850 and manage Early Start compatibility without manually modifying game files.

## Features

- Start Transport Fever 3 in 1850
- Automatic TF3 installation detection
- Safe GUI patch with backup/revert
- TF3 update detection
- Compatibility Mod generator
- 24 mandatory Early Start overrides
- Resource Browser
- Vanilla / Mod.IO / local mods
- Easy and Advanced Mode
- 9 UI languages
- Portable Windows application

## Installation

1. Download TF3_Early_Start_Manager_v1.0.0_Windows_x64.zip
2. Extract the complete folder
3. Start TF3 Early Start Manager.exe

No Python installation required.
