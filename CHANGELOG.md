# Changelog

## 1.0.0

First stable source release.

- Modular architecture for scanner, TF3 discovery/patching, Compatibility Mod, localization, models and UI
- Persistent content cache with Vanilla, Mod.IO and Local sources
- Guarded 1850 patch install/revert and TF3 update detection
- Compatibility Mod with 24 mandatory Easy-1850 baseline overrides
- Localized Resource Tree and nine UI languages
- Centralized versioning and minimal application bootstrap
- RC fixes for Resource Preview/Mod Description, reset selection, Settings scan behavior, dynamic primary actions and Advanced UI layout
